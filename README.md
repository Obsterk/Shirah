# Happy Birthday Shirah

Pink-themed birthday page with Naa's letter, throwback polaroids, linked soundtrack, year goals, photo dump, and messages from Mum & Dad.

## Setup

1. **`config.js`** — text is already filled in; swap Spotify `url` fields for direct song links if you like.
2. **`assets/images/`**
   - `hero.jpg` — main portrait
   - `throwback-1.jpg` … `throwback-6.jpg` — polaroids
   - `dump-1.jpg` … `dump-8.jpg` — photo dump
   - `tape.jpg` — optional cassette photo (CSS tape shows if missing)
   - `album-cover.jpg` — optional player art
3. **`assets/audio/birthday-song.mp3`** — background song for the floating player.

Open **`index.html`** in a browser to preview.
